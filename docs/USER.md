# AmongUs-Bot 使い方

Discord のボイスチャット（VC）にいる全員を、まとめてミュート／ミュート解除するためのアプリです。  
Among Us のゲーム中、**ホスト（運用者）が 1 人**このアプリを動かして、VC 全員のマイクを一括制御します。

インストールは不要です。ZIP を解凍して `AmongUs-Bot.exe` を起動します。

> **用語の説明**
> - **運用者** … AmongUs-Bot を起動して、全員ミュート／解除を押す人（ホスト）
> - **サーバーミュート** … Discord が強制的にマイクをオフにする機能（赤いマイクのアイコンが付く）
> - **セルフミュート** … 自分でマイクをオフにした状態。本アプリの「ミュート解除」では**セルフミュートはそのまま**です

---

## 誰が何をするか

| 誰 | アプリは必要？ | やること |
|---|---|---|
| **サーバー管理者** | 不要 | Bot の作成・招待・ロール調整、**ID の共有**（初回だけ） |
| **運用者（あなた）** | **必要** | アプリを起動して、ゲーム中にミュート操作する |
| **Among Us の参加者** | **不要** | 普通に VC に入るだけ。Discord 上でミュートされる |

### 典型的な流れ

1. 信頼できる人から ZIP を受け取るか、[リポジトリ](https://github.com/oshiiiso/discord-bot-amongus) を clone して自分でビルドする
2. Discord サーバーの**管理者に依頼**する  
   → Bot の作成・招待・トークンの受け渡し、**サーバー ID と VC チャンネル ID の共有**
3. **運用者 1 人**がトークンと ID をアプリに入力して使い始める
4. ゲーム中、運用者が全員ミュート／解除を操作する

> **重要: トークンは同時に 1 人だけ**  
> Bot トークンはパスワードと同じです。同じトークンで複数人が別 PC から同時に起動すると、どちらかが切断されます。  
> **運用者 1 人・1 台の PC**で使ってください。

## セットアップ

### 1. ZIP を用意する

**受け取った場合**

1. ZIP を**右クリック** → **すべて展開**
2. 解凍先は固定のフォルダを推奨（例: `C:\Tools\AmongUs-Bot\`）

**自分でビルドする場合**

リポジトリの README に従い `npm run dist` を実行し、`release/` 内の ZIP を使います。

### 2. フォルダの中身

```
AmongUs-Bot/
  AmongUs-Bot.exe    ← これを起動
  .portable          ← 同梱ファイル（削除しない）
  .env               ← 問い合わせ先など
  data/              ← 初回起動後に作成（設定が入る）
  logs/              ← 初回起動後に作成
```

- **exe だけ別の場所にコピーしないでください。** 設定は exe と同じフォルダに保存されます。
- フォルダごとコピーすれば、別 PC へ設定ごと移せます。

### 3. 初回起動

1. **AmongUs-Bot.exe** をダブルクリック
2. 「**はじめに**」画面で次を入力する
   - **Bot トークン**
   - **プリセット名**（例: `ゲーム用VC`）
   - **サーバー ID**
   - **VC チャンネル ID**
3. **接続する** を押す
4. 画面上部が **接続済み**（緑）になれば OK
5. 2 回目以降は自動で接続します

## はじめに（初回セットアップ・詳細）

### 手順 A: サーバー管理者にお願いすること

| もらうもの | 用途 |
|---|---|
| **Bot トークン** | アプリの初回接続に使う（パスワード扱い） |
| **サーバー ID** | VC プリセットに入力する |
| **VC チャンネル ID** | ミュート対象のボイスチャンネルを指定する |

管理者側の作業:

1. [Discord Developer Portal](https://discord.com/developers/applications) で Bot を作成
2. **Bot** タブでトークンを発行し、運用者にだけ渡す
3. **OAuth2** → **URL Generator** で `bot` スコープと **Mute Members** 権限を付けて招待
4. **サーバー設定** → **ロール** で、Bot のロールを参加者より**上**に置く
5. 開発者モードでサーバー ID・VC チャンネル ID をコピーして送る

#### ID の調べ方

1. **ユーザー設定** → **詳細設定** → **開発者モード** を ON
2. サーバー名を右クリック → **サーバー ID をコピー**
3. ボイスチャンネル名を右クリック → **チャンネル ID をコピー**

### 手順 B: VC プリセットを追加・変更する

1. 設定（⚙）→ **VC** タブ
2. **追加** または既存プリセットを編集
3. **保存**

## ゲーム中の使い方

1. **AmongUs-Bot.exe** を起動（**接続済み**であること）
2. プリセットを選ぶ
3. 参加者が VC に入る
4. **全員ミュート** → 確認で OK
5. 終了後 **ミュート解除**

### ショートカット

| 操作 | キー |
|---|---|
| 全員ミュート | `Ctrl` + `Shift` + `M` |
| ミュート解除 | `Ctrl` + `Shift` + `U` |

### トレイに残す

1. 設定 → **動作**
2. **×ボタンでトレイに最小化** をオン → **保存**

| 表示 | 意味 |
|---|---|
| 緑 · **接続済み** | Bot が Discord に接続できている |
| 赤 · **エラー** | トークン誤りなど。設定 → Bot を確認 |
| **ミュート中** | 後から VC に入った人も自動ミュート |
| 操作履歴 | 直近のミュート／解除 |

## バージョンアップ

新しい ZIP を受け取ったら:

1. **`data/` をバックアップ**
2. 新しい ZIP を展開（または `data/` だけコピー）
3. 起動して動作確認

## よくある質問

**Q. 参加者もアプリが必要？**  
A. 不要です。運用者だけが使います。

**Q. 設定の保存場所は？**  
A. exe と同じフォルダの `data/` と `logs/` です。

**Q. 運用者を複数人にしたい**  
A. 同じ Bot トークンは同時に 1 つだけ接続できます。交代運用か、Bot を分けてください。

**Q. VC に誰もいなくてもミュートできる？**  
A. できます。あとから入った人も自動ミュートされます。

**Q. ミュート解除でセルフミュートも戻る？**  
A. 戻りません。サーバーミュートだけが外れます。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 接続済みにならない | トークンを確認。設定 → Bot |
| ミュートされない | Bot のロール順位と「メンバーをミュート」権限を確認 |
| 途中で切断された | 別 PC で同じトークンが使われていないか確認 |
| ショートカットが効かない | アプリが起動しているか、キーが被っていないか確認 |
| ×で終了してしまう | 設定 → 動作 でトレイ最小化をオン |
| **起動できない（Smart App Control）** | 下記を参照 |

### Smart App Control で起動できない場合

未署名の exe のため、Windows 11 で **Smart App Control** がオンだとブロックされることがあります。

1. **設定** → **プライバシーとセキュリティ** → **Windows セキュリティ** → **アプリとブラウザの制御**
2. **Smart App Control の設定** → **オフ**
3. exe を再起動

ZIP を受け取った場合は、**プロパティ** → **ブロックの解除** も試してください。

> 信頼できる人から渡されたビルド、または自分でビルドしたものだけ使ってください。

ログは `logs/` に保存されます。不具合報告は [Issues](https://github.com/oshiiiso/discord-bot-amongus/issues) へ。
