# AmongUs-Bot 使い方（運用者向け）

Discordのボイスチャット（VC）にいる全員を、まとめてミュート／ミュート解除するためのアプリです。  
Among Usのゲーム中、**ホスト（運用者）が1人**このアプリを動かして、VC全員のマイクを一括制御します。

> **用語の説明**
> - **運用者** … AmongUs-Botを起動して、全員ミュート／解除を押す人（ホスト）
> - **サーバーミュート** … Discordが強制的にマイクをオフにする機能（赤いマイクのアイコンが付く）
> - **セルフミュート** … 自分でマイクをオフにした状態。本アプリの「ミュート解除」では**セルフミュートはそのまま**です

---

## 誰が何をするか

| 誰 | アプリは必要？ | やること |
|---|---|---|
| **サーバー管理者** | 不要 | Botの作成・招待・ロール調整、**IDの共有**（初回だけ） |
| **運用者（あなた）** | **必要** | アプリを起動して、ゲーム中にミュート操作する |
| **Among Usの参加者** | **不要** | 普通にVCに入るだけ。Discord上でミュートされる |

### 典型的な流れ

1. 運用者がAmongUs-Botを見つける
2. Discordサーバーの**管理者に依頼**する  
   → Botの作成・招待・トークンの受け渡し、**サーバーIDとVCチャンネルIDの共有**
3. **運用者1人**がトークンとIDをアプリに入力して使い始める
4. ゲーム中、運用者が全員ミュート／解除を操作する

> **重要: トークンは同時に1人だけ**  
> Botトークンはパスワードと同じです。同じトークンで複数人が別PCから同時に起動すると、どちらかが切断されます。  
> **運用者1人・1台のPC**で使ってください。参加者全員がアプリを入れる必要はありません。

## 初回セットアップ

### 手順A: サーバー管理者にお願いすること

管理者に以下をお願いしてください。

| もらうもの | 用途 |
|---|---|
| **Botトークン** | アプリの初回接続に使う（パスワード扱いで運用者だけに渡す） |
| **サーバーID** | 設定画面のVCプリセットに入力する |
| **VCチャンネルID** | ミュート対象のボイスチャンネルを指定する |

あわせて、管理者側で以下の作業もお願いします。

1. [Discord Developer Portal](https://discord.com/developers/applications) でBotを作成する
2. **Bot** タブでトークンを発行し、**運用者にだけ**渡す
3. **OAuth2** → **URL Generator** で `bot` スコープと **Mute Members** 権限を付けて、サーバーに招待する
4. **サーバー設定** → **ロール** で、Botのロールを参加者より**上**に置く
5. **開発者モード**をONにし、サーバーID・VCチャンネルIDをコピーして運用者に送る（下記「IDの調べ方」参照）

> **運用者が自分でIDを調べられる場合**  
> 同じDiscordサーバーに入っていて、開発者モードをONにできるなら、手順Cの「IDの調べ方」で自分で取得しても構いません。  
> わからない場合は、管理者に上記3点をまとめてもらうのが確実です。

管理者自身が運用者の場合は、この手順を自分で行います。

#### 管理者向け: Bot作成の詳細手順

1. ブラウザで [Discord Developer Portal](https://discord.com/developers/applications) を開く
2. 右上の **New Application** を押し、名前を付けて作成する
3. 左メニューの **Bot** を開く
4. **Reset Token** を押してトークンを表示し、**コピー**する
5. 左メニューの **OAuth2** → **URL Generator** を開く
6. **SCOPES** で `bot` にチェックを入れる
7. **BOT PERMISSIONS** で **Mute Members**（メンバーをミュート）にチェックを入れる
8. 下に表示されたURLをコピーし、ブラウザで開いてサーバーにBotを追加する
9. Discordアプリで **サーバー設定** → **ロール** を開き、Botのロールを参加者より上にドラッグする
10. **ユーザー設定** → **詳細設定** → **開発者モード** をONにする
11. サーバー名・ボイスチャンネル名を右クリックして **IDをコピー** し、運用者に送る

### 手順B: アプリを起動する（運用者）

1. 配布されたZIPファイルを**右クリック** → **すべて展開**（または解凍）する
2. フォルダ内の **AmongUs-Bot.exe** をダブルクリックする
3. 初回は「**はじめに**」画面が出るので、管理者から受け取った**Botトークン**を貼り付けて **接続する** を押す
4. 画面上部が **接続済み**（緑）になればOK
5. 2回目以降は自動で接続します

> Windowsから「不明なアプリ」と警告が出た場合  
> **詳細情報** → **実行** を選んでください（配布元を信頼できる場合）。

### 手順C: 操作するVCを登録する（運用者）

1. アプリ右上の **⚙（歯車）** を押して設定を開く
2. **VC** タブで **追加** を押す
3. 管理者から受け取った（または自分で調べた）次の2つを入力する
   - **サーバーID**
   - **VCチャンネルID**
4. **名前** はわかりやすい名前を付ける（例: `ゲーム用VC`）
5. 画面下の **保存** を押す

#### IDの調べ方（自分で調べる場合）

管理者からもらえないときは、Discord上で次の手順で調べられます。

1. **ユーザー設定**（歯車）→ **詳細設定** → **開発者モード** をON
2. サーバー一覧でサーバー名を**右クリック** → **サーバーIDをコピー**
3. ボイスチャンネル名を**右クリック** → **チャンネルIDをコピー**

## ゲーム中の使い方（運用者）

1. **AmongUs-Bot.exe** を起動する（**接続済み**になっていること）
2. ドロップダウンで操作対象のVCを選ぶ
3. 参加者がそのVCに入る
4. **全員ミュート** を押す → 確認画面でOK  
   → VCの全員にサーバーミュートがかかる（参加者側はアプリ不要）
5. ゲーム終了後、**ミュート解除** を押す

### キーボードショートカット

ゲーム中にキーだけで操作できます。**アプリは起動したまま**にしてください。

| 操作 | キー |
|---|---|
| 全員ミュート | `Ctrl` + `Shift` + `M` |
| ミュート解除 | `Ctrl` + `Shift` + `U` |

### ゲーム中も動かしっぱなしにしたい場合

初期設定では、×ボタンを押すと**アプリが終了**します。

1. 設定（⚙）→ **動作** タブを開く
2. **×ボタンでトレイに格納** にチェックを入れて **保存**
3. 以降、×を押すと画面は消えますが、タスクバー右下のトレイに残ります

## 画面の見方

| 表示 | 意味 |
|---|---|
| 緑 · **接続済み** | BotがDiscordに接続できている |
| 赤 · エラー | トークンが間違っているなど。設定 → Bot を確認 |
| **ミュート中** バッジ | ミュートセッションが有効。後からVCに入った人も自動ミュート |
| 操作履歴 | 直近のミュート／解除の記録 |

## よくある質問

**Q. 参加者もアプリを入れる必要がある？**  
A. ありません。運用者だけがアプリを使います。参加者はDiscordのVCに入っているだけで、サーバーミュートの対象になります。

**Q. 運用者を複数人にしたい**  
A. 同じBotトークンは同時に1接続だけです。複数人で使う場合は、**交代で1人ずつ**運用するか、Botを分けて用意する必要があります。

**Q. VCに誰もいなくてもミュートできる？**  
A. できます。「ミュート中」状態になり、あとから入ってきた人も自動でミュートされます。

**Q. ミュート解除すると、自分のマイクOFFも戻る？**  
A. 戻りません。サーバーミュートだけが外れます。

**Q. 複数のVCを使い分けたい**  
A. 設定 → VC でプリセットを複数登録し、ドロップダウンで切り替えます。

**Q. アプリを閉じたらショートカットは使える？**  
A. 使えません。ショートカットを使うときはアプリを起動したままにしてください（トレイ常駐でも可）。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 接続済みにならない | トークンをコピーし直す。設定 → Bot で確認 |
| ミュートされない | 管理者にBotのロール順位と「メンバーをミュート」権限を確認してもらう |
| 途中で切断された | 別のPCで同じトークンが使われていないか確認する |
| ショートカットが効かない | アプリが起動しているか確認。他のソフトとキーが被っていないか確認 |
| ×で終了してしまう | 設定 → 動作 で「トレイに格納」をオンにする |

問題調査用のログは、アプリフォルダ内の `logs` フォルダに保存されています。

## 補足（配布形式について）

- **ZIP版（ポータブル）** … フォルダ内に `.portable` がある場合、設定はexeと同じフォルダに保存されます。フォルダごとコピーすれば設定も引き継がれます。
- **通常版** … 初回に保存先を選べます。あとから変更する場合は 設定 → 動作 → **変更** から行えます。
